Qué resuelve

Lee copias de Excel, conserva el original, aplica reglas conocidas para Laja, Mulchén y Tomé, y deja productos editables para revisión humana.

Qué requiere revisión

CSMP no tiene un lector ni escritor RUS conectado. Las bitácoras y el registro deben revisarse en RUS. La creación del borrador en Outlook también debe comprobarse en la cuenta abierta.

Regla de seguridad

El texto propuesto no prueba que la gestión se haya hecho. Solo una confirmación verificable en RUS debe marcar una observación como registrada.

Instalación y preparación

Prueba recomendada: extrae el ZIP completo en una carpeta nueva. El ejecutable necesita toda la carpeta _internal.
  1. Descarga el paquete Windows y extráelo en una carpeta permanente.
  2. Para el descargador, abre Iniciar.cmd y carga la carpeta extension en chrome://extensions con modo desarrollador.
  3. Abre Chrome, entra personalmente a SITFA y deja abierta la pantalla Seguimiento.
  4. Abre CSMP_Integral.exe. La configuración de prueba se guarda en LOCALAPPDATA/CSMP_Personal.
  5. En CSMP selecciona el ejecutable del descargador solo la primera vez y conserva ambas carpetas.

No compartas credenciales, códigos de conexión, HAR ni Excel con información personal. El manual describe el flujo local y usa capturas ficticias.

Productos locales
  1. En CSMP pulsa Descargar y analizar y elige el modo.
  2. En el descargador selecciona tribunales, modalidades, pestaña y período. La carga mínima de actividad es de 60 días en bloques de hasta 30.
  3. Espera la verificación de cada Excel. No cierres Chrome ni hagas otra exportación con la misma sesión.
  4. Cuando vuelva el resultado, revisa las alertas de resoluciones firmadas y los datos faltantes.
  5. Exporta la copia actual. La copia lleva bordes, campos editables y mantiene el archivo original intacto.
Cobertura: si SITFA incluye firmas posteriores al día consultado, el resultado se marca como cobertura parcial. «Sin coincidencias» no demuestra ausencia de movimientos si el portal no permite una cobertura completa.

Pantalla Trabajo

Selecciona el modo, el Excel y la hoja. El asistente conserva la procedencia, muestra el RIT, tribunal, programa, estado y observación, y prioriza las incidencias.

Editar una observación
  1. Selecciona una fila y revisa el detalle de la causa.
  2. Edita la observación y, cuando corresponda, FECHA_OBS, TT, CC y RES.
  3. Exporta la copia actual. El contenido visible se captura aunque no hayas pulsado antes Aplicar edición.
  4. Comprueba la fecha o tiempo de espera. Si el origen está vacío, el producto muestra Sin dato para evitar inventar valores.
Buscar y filtrar

Usa el buscador para RIT, nombre, tribunal o programa. «Con aviso» muestra solo incidencias; «Con resolución» muestra filas con resolución; «Excluidos» conserva la trazabilidad sin incluir la fila en correos.

Correos: preparación de borradores

La pantalla prepara borradores editables. No envía correos automáticamente. Puedes elegir Solo programas, Solo tribunales o Ambos, y aplicar modalidades y tribunales como filtros independientes.

  1. Pulsa Preparar tipo o Preparar todos. Si el resultado es vacío, lee el mensaje: indica modalidad, tribunal, exclusión o falta de reglas.
  2. Selecciona una tarjeta. Revisa Para, CC institucional, asunto, cuerpo y adjuntos.
  3. Corrige el texto o retira un adjunto con la “x”. Una dirección inválida queda visible para corregirla, pero bloquea el guardado de ese borrador.
  4. Pulsa Guardar borradores. Verifica en Outlook que el borrador corresponda al RIT y a la nómina que revisaste.
Mulchén: RTA, RTT y RVA se agrupan como Residencial; la normalización acepta mayúsculas, tildes, diéresis y abreviaturas. Si no aparece una tarjeta, revisa primero la modalidad y el tribunal seleccionado.

Resoluciones y Word

Los proyectos se agrupan por tribunal + RIT + tipo. RES puede indicar PC_IE, PC_INFO o NOMENCL; vacío significa que no corresponde proyecto.

  1. Selecciona el tipo y pulsa Preparar / actualizar proyectos.
  2. Revisa el origen: definido en RES, ajustado manualmente o sugerencia automática.
  3. Abre la matriz si necesitas inspeccionarla. Para Tomé, no se inventa una matriz: debes incorporarla o dejar el proyecto pendiente.
  4. Genera un Word individual o conjunto. Los datos faltantes aparecen como [COMPLETAR …].

Recuperación después de un corte

La recuperación evita repetir trabajo: cada solicitud conserva modo, huella, tribunal, Excel y estado.
  1. Abre CSMP otra vez y entra a Resultados.
  2. Pulsa Recuperar descarga y elige la solicitud que coincide con el modo y la fecha.
  3. Espera la comprobación de huella y columnas. Solo se incorpora una descarga que coincide con la solicitud.
  4. Revisa las ediciones archivadas y continúa desde Correos, Resoluciones o Exportar copia actual.

Si Excel se cerró durante una exportación, el original permanece separado. Corrige el archivo de salida o elige otra carpeta y vuelve a exportar.

Personalizar la vista

Abre Configuración → Básico → Vista. Guarda varias distribuciones con un nombre, aplica una vista guardada o restaura la anterior para deshacer el cambio.

  1. Elige Trabajo, Resoluciones o Historial y pulsa Cargar columnas.
  2. Selecciona una columna, cambia Visible o su ancho y pulsa Ajustar columna. Subir y Bajar cambian el orden. Conserva al menos una columna visible.
  3. Pulsa Aplicar columnas y, si lo necesitas, ajusta la fuente de las tablas y los editores entre 10 y 22 puntos.
  4. Pulsa Guardar vista. Exportar JSON crea un archivo portable; Importar JSON lo valida y lo incorpora sin aplicarlo hasta que pulses Aplicar vista.

Al cerrar se conservan los filtros, columnas, anchos, fuente y tamaño de ventana. Las selecciones ocultas por el buscador se mantienen en la sesión del trabajo. El archivo de vista guarda preferencias y textos de búsqueda; no contiene las filas del caso.

Preguntas frecuentes

¿Por qué no aparece un borrador?

Comprueba el modo de la hoja, el filtro Solo programas/tribunales, la modalidad, el nombre del tribunal y las exclusiones. Para Mulchén, usa Residencial para RTA/RTT/RVA.

¿Qué significa “Sin dato”?

Que el Excel no entregó una fecha de vencimiento, espera o egreso utilizable. Es una alerta para revisar la fuente, no una fecha calculada por el asistente.

¿El asistente lee o escribe en RUS?

No. El código contiene contratos y análisis de bitácora sobre datos proporcionados, pero esta entrega no conecta una sesión RUS para leer, guardar ni confirmar observaciones. No se debe marcar una gestión como realizada ni completar su fecha hasta comprobarla directamente en RUS.

¿Qué hago si el ejecutable no abre?

Extrae el ZIP completo en una carpeta nueva y no mezcles el ejecutable con otra carpeta _internal. Si la ventana abre pero parece una versión anterior, revisa Configuración → Avanzado → Diagnóstico: muestra versión, commit, origen y las rutas del ejecutable y del módulo CSMP que se cargó.

¿Puedo usar otro tribunal?

La disponibilidad depende de las pantallas y opciones que RUS exponga al descargar. Las reglas históricas de correos y las matrices Word están configuradas solo para Laja, Mulchén y Tomé. La auditoría individual de bitácora para todos los tribunales sigue pendiente de conectar y verificar.

¿Qué datos se guardan?

Los productos y diarios se guardan localmente. El descargador no guarda cookies ni contraseñas y los resúmenes no incluyen filtros privados. Trata los Excel y borradores como información reservada.

Cuando necesites soporte

Conserva el modo, tribunal, nombre de la hoja, hora aproximada, mensaje mostrado y los archivos resumen.json o recibos locales. No incluyas credenciales, códigos de conexión, nombres de niños, RUT ni capturas de una causa real.

La auditoría técnica está en AUDITORIA_COMPLETA_20261005.md. El flujo de pruebas está en GUIA_PRUEBAS_INTEGRALES.md.
